
# TravelRoute Pro — Travel Itinerary Planner

[Live Demo on PartyRock](https://partyrock.aws/u/shubhi28srivastava/NzTzV-OEz/TravelRoute-Pro)

Enter destinations (comma-separated) and number of days, and the app generates an optimized itinerary that minimizes travel time between cities.

## Features
- Distance-aware itinerary planning  
- Day-by-day travel schedule  
- Groups nearby cities to reduce transit time  

## Tech
- Built using **Amazon PartyRock** (powered by Bedrock) for rapid no-code prototyping
